# Traider

An experiment: can an LLM agent trade US stocks by itself? Five participants trade on paper money under rules that code enforces, and the result is compared with random bots and with the market. The project documentation is in Russian.

Эксперимент: умеет ли LLM-агент торговать акциями США сам. Агент сам решает, что смотреть и что покупать. Все ограничения риска исполняет код, и обойти их модель не может. Проверка идёт прогоном вперёд на бумажном счёте, без теста на истории: прошлые котировки модель помнит из обучения, и такой тест завышал бы результат.

Это исследовательский проект, а не инвестиционная рекомендация.

## Состояние

Пилот на бумажном счёте начат 16 ноября 2026 года. Результатов пока нет. Режим реальных денег в коде есть, но включается только вручную владельцем.

## Как устроен эксперимент

Пять участников, у каждого 1000 долларов и одна сессия в торговый день:

| Участник | Модель | Чем отличается |
|---|---|---|
| `haiku` | Claude Haiku 5.5 | младшая модель |
| `sonnet` | Claude Sonnet 5.5 | средняя модель |
| `opus-a` | Claude Opus 5.5 | торгует на бумажном счёте Alpaca |
| `opus-b` | Claude Opus 5.5 | двойник `opus-a` на встроенном счёте |
| `opus-analyst` | Claude Opus 5.5 | перед сессией получает сводку от агента-аналитика |

Разница между двумя одинаковыми участниками `opus-a` и `opus-b` служит меркой случайности: остальные различия что-то значат, только если заметно больше неё.

В сессии агент видит свой счёт, позиции, журнал и заметки, может смотреть цены и новости, искать в сети, покупать и продавать бумаги из списка (S&P 500 и 17 биржевых фондов) и записывать прогнозы.

## Клетка: правила, которые исполняет код

- одна позиция не больше 20% капитала, заявка не меньше 20 долларов;
- у каждой покупки обязателен стоп на 3–15% ниже цены;
- суммарный риск по открытым позициям не больше 8% капитала;
- не больше 3 покупок за сессию, не больше 40 ходов и 8 поисков в сети;
- если капитал падает ниже 85% от своего максимума, участник выбывает: его позиции продаются, прогон окончен.

Заявку, которая нарушает правило, код отклоняет и объясняет агенту причину.

## Как меряется результат

Прибыль за два месяца сама по себе не отличает умение от везения, поэтому меряется несколько вещей:

- **Случайные боты.** Тысяча ботов повторяет действия участника (когда и на сколько купить), но с случайной бумагой. Результат участника показывается местом среди них: 50 значит «как монетка».
- **Рынок.** Сравнение с фондом SPY: «купил и держал» и SPY с той же долей вложенных денег, что у участника.
- **Прогнозы.** Каждый день агент называет вероятность того, что бумага обгонит рынок за 5 торговых дней. Прогнозы оцениваются по Брайеру и сравниваются с эталоном «всегда называть среднюю долю».
- **Стоимость модели.** Расход на каждую сессию записывается и входит в отчёт.

Вердикт выносится по порогам, заданным до старта, и один раз: после конца прогона или при выбывании участника.

## Что есть в репозитории

- `traider/` — код: клетка, счета (встроенный и Alpaca), сессия агента, тик, повтор сделок, отчёт, страница аналитики, пауза и остановка, страница управления.
- `tests/` — тесты. Сеть им не нужна; два теста с пометкой `paper` обращаются к бумажному счёту и по умолчанию пропускаются.
- `wiki/` — база знаний проекта в формате WikiKnowledge: устройство, правила, порядок действий, журнал решений. Начать можно с `wiki/articles/runbook.md`.
- `docs/superpowers/specs/` — дизайн эксперимента, `docs/superpowers/plans/` — планы реализации, `docs/mockups/` — макет страницы аналитики.
- `ops/` — шаблоны заданий launchd для macOS: тик каждые 15 минут и сервер страницы управления.
- `data/universe.txt` — список бумаг.

## Запуск

Нужны Python 3.11 или новее, [uv](https://docs.astral.sh/uv/), ключи бумажного счёта Alpaca и ключ Anthropic API.

```bash
uv sync
cp .env.example .env            # вписать ключи; файл в git не попадает
uv run pytest -q                # тесты, без сети
cp experiment.example.toml experiment.toml
uv run traider start experiment.toml
uv run traider tick             # один обход: проверка стопов и запаса прочности, сессии, отчёт
uv run traider status
```

Тик делает что-то только в часы торгов США; сессии идут в окне с 10:00 до 15:30 по Нью-Йорку. Каждая сессия тратит деньги на API модели: худший случай для конфига из примера команда `start` печатает сама.

Остальные команды:

| Команда | Что делает |
|---|---|
| `uv run traider report` | собирает отчёт и страницу аналитики `runs/<эксперимент>/dashboard.html` |
| `uv run traider serve` | страница аналитики с кнопками «Пауза», «Продолжить», «Остановить всё» на `http://127.0.0.1:8787` |
| `uv run traider pause`, `resume` | пауза и её снятие; день паузы не считается ни сессией, ни пропуском |
| `uv run traider stop <эксперимент> --yes` | остановка навсегда: позиции продаются, прогон идёт к завершению |

Полный порядок действий, расписание и переход от пилота к основному прогону описаны в `wiki/articles/runbook.md`.

## Страница аналитики

Один файл HTML без внешних зависимостей: сводка и вердикты, кривые капитала на фоне случайных ботов, расходы, сетка сессий (по клику видно, что агент смотрел, что решил и что отклонила клетка), открытые позиции, закрытые сделки, прогнозы и происшествия. Страница открывается с диска; сервер нужен только для кнопок управления и слушает один адрес `127.0.0.1`.

## Ограничения

- Бумажный счёт Alpaca: данные только с биржи IEX, дивиденды не учитываются, исполнение оптимистичнее настоящего.
- 20–40 сделок за два месяца мало для уверенного вывода, поэтому результат читается вместе со сравнениями выше.
- Внутридневной торговли, шортов, опционов, плеча и крипты в проекте нет.
