# Вселенная бумаг

Агент торгует только тем, что есть в `data/universe.txt`: по тикеру на строку, по алфавиту, без повторов. Любой другой тикер клетка отклоняет ([[cage-rules]]).

## Откуда состав

- Состав S&P 500 взят из открытого набора данных: https://raw.githubusercontent.com/datasets/s-and-p-500-companies/main/data/constituents.csv, получен 2026-11-14.
- К нему добавлены 17 ETF: SPY, QQQ, IWM, DIA, XLK, XLF, XLE, XLV, XLI, XLY, XLP, XLU, XLB, XLRE, XLC, TLT, GLD. Кредитных плечей и обратных фондов (TQQQ, SQQQ, SPXL, SH и подобных) в списке нет.
- Тикеры классов B пишутся через точку: BRK.B, BF.B.
- Итого 520 бумаг. Файл собран без фильтра по Alpaca: ключей на момент сборки не было.

## Как собирается и фиксируется

Список строит `tools/build_universe.py`. С флагом `--alpaca` он оставляет только бумаги, которые Alpaca разрешает покупать долями, и для этого нужны ключи в `.env`. Пока флаг не использован, список может содержать бумаги без дробных долей; сборку с фильтром должен запустить владелец или ассистент с его согласия.

Файл лежит в репозитории, а при старте эксперимента список читается и записывается в конфиг прогона ([[run-files]]). Поэтому состав остаётся неизменным до конца прогона, даже если индекс потом меняется.

## Рыночные данные

Котировки, свечи и новости приходят с бесплатной ленты IEX. Она беднее полной ленты SIP: объёмы и некоторые сделки в ней не видны. Любая ошибка связи с Alpaca поднимает исключение, пустым ответом сбой не прикрывается.
