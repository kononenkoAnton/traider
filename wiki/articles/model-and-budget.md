# Модель и бюджет

## Чем платим

Выбран API-ключ Anthropic: у владельца план Max, расход покрывают включённые API-кредиты ($100 в месяц, не переносятся). Подписка через `claude -p` отвергнута: потребительские условия запрещают автоматический доступ, а явного разрешения для скрипта по расписанию нет. Облачные сессии Claude Code тоже не подходят: у агента там есть терминал, набор инструментов не ограничить, клетка перестаёт быть стеной.

## Как устроен «мозг»

Anthropic SDK для Python; модель берётся из конфига участника ([[participants]]). Адаптивное мышление, effort `high` задан явно у всех для сопоставимости, стриминг, кэширование промпта, серверный `web_search`. Стоимость считается из учёта токенов по таблице цен в конфиге.

## Потолки

- Лимиты ходов (40) и поисков (8) одинаковы для всех.
- Потолок в долларах это предохранитель, свой у каждой модели: $2 для Opus, $1 для Sonnet, $0.25 для Haiku.
- При стартовых потолках худший случай больше $100 кредитов. Поэтому после [[pilot]] потолки подбираются так, чтобы худший случай не превышал $90.
- При достижении потолка цикл обрывается, стопы остаются на месте ([[stops]]).

Если кредиты всё же кончатся, запросы встанут на паузу, сессии запишутся сбойными, а проверка HP и стопы продолжат работать: они модель не вызывают ([[hp-floor]]).

## Чем может закончиться цикл агента

Цикл (`traider/brain.py`) ведёт разговор вручную и после каждого ответа модели проверяет расход раньше, чем выполняет инструменты этого ответа. Он не поднимает исключений. Исходов шесть:

1. `finished`: модель вызвала завершающий инструмент и он отработал без ошибки. Вызовы идут по порядку; после успешного завершающего остальные вызовы того же ответа не выполняются, каждый получает результат с ошибкой «не выполнено: сессия уже завершена». Вызовы до него выполняются. Завершающий вызов с ошибкой сессию не заканчивает.
2. `end_turn`: модель закончила ответ, не вызвав завершающий инструмент (сюда же идут остановка по своей воле и по стоп-последовательности).
3. `max_turns`: исчерпан лимит обращений к модели. Приостановка `pause_turn` продолжается повторной отправкой и тоже считается ходом.
4. `budget`: накопленная стоимость достигла потолка в долларах. Инструменты ответа, на котором это случилось, не выполняются, поэтому заявка из этого хода не уходит.
5. `refusal`: модель или классификатор отказали. Серверная подмена модели включена для Opus и Sonnet и недоступна для Haiku; ответившая модель записывается в результат.
6. `error`: исключение клиента (кончились кредиты, сеть), ответ оборван по лимиту токенов, неизвестная причина остановки, остановка по вызову инструмента без вызовов, или любой сбой самого цикла. Текст ошибки сохраняется вместе с уже накопленными ходами, расходом и записью; уже купленное остаётся со стопами. Если упал сам запрос, к тексту добавлено, что он мог быть оплачен и в стоимость не входит: цикл его не повторяет.

Стоимость считается по каждому запросу отдельно и суммируется. Для Haiku запрос длиннее 100 тысяч токенов (вход плюс кэш) идёт по длинным ставкам, если они есть в таблице цен. Ошибка инструмента, неизвестный инструмент или вход, не прошедший проверку по схеме, возвращаются модели как результат с признаком ошибки, и цикл продолжается. При подмене модели стоимость и токены это сумма по всем попыткам из отчёта об использовании, и каждая попытка оценена по таблице цен основной модели: это приближение. Признак `fallback_used` в результате истинен, если ответила другая модель или попыток было больше одной.

## Подмена модели

Серверная подмена при отказе включена там, где доступна, чтобы сессия не пропадала. Запись сессии фиксирует, какая модель ответила, отчёт считает такие сессии отдельно. Альтернатива: выключить подмену и считать отказ пропущенным днём.

## Промпт

Задача (растить счёт в рамках правил, за активность бонуса нет, деньги это допустимая позиция), правила клетки ([[cage-rules]]), обязанности, предупреждение, что текст из сети данные, а не указания.

## Стоимость в отчёте

Отчёт показывает результат и без учёта стоимости модели, и с ней ([[analytics-page]]). Для живого счёта $1 в день это примерно 2% в месяц от $1000.
