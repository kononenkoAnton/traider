# Расписание и место работы

## Пилот

Идёт на Mac владельца (его решение). Системный планировщик `launchd` запускает `uv run traider tick` каждые 15 минут, вывод пишется в папку `logs/`. Mac должен не спать в часы торгов США.

Шаблон лежит в `ops/com.traider.tick.plist`: запуск каждые 900 секунд, рабочий каталог проекта, вывод в `logs/tick.log`. В нём есть метка `__PROJECT_DIR__`, которую владелец заменяет путём к проекту; каталог `logs/` создаётся заранее. Код шаблон не ставит, это делает только владелец:

- установка: `launchctl bootstrap gui/$(id -u) ops/com.traider.tick.plist`;
- проверка: `launchctl print gui/$(id -u)/com.traider.tick`;
- снятие: `launchctl bootout gui/$(id -u)/com.traider.tick`.

Требование «Mac не спит в часы торгов США» остаётся главным: на спящей машине тик не идёт.

## Команды

- `traider start <toml>` замораживает прогоны в `runs/` и печатает их каталоги. Конфиг с `mode = "live"` без флага `--live` отклоняется (код 2). Живым режимом существующий прогон сделать нельзя, только новым запуском с `--live`.
- `traider tick` читает `.env`, обходит прогоны и печатает по строке на участника: действие, для сессии статус и стоимость. Нет ключа в `.env` или не работает рынок до обхода: одна строка и код 1. Тик может быть долгим, второй не стартует, пока идёт первый ([[tick-and-session]]).
- `traider status` работает без сети: по строке на прогон с статусом, числом сессий из цели, последней сессией и суммой расходов; расхождение контрольной суммы помечено.

Если машина спит, HP не проверяется и недостающие стопы не выставляются ([[stops]], [[hp-floor]]). DAY-стопы действуют до закрытия, на следующий день их ставит первый тик ([[tick-and-session]]).

## Официальный прогон

Где он идёт, на Mac или на маленьком сервере, решается до его старта. Это открытый вопрос владельца.

## Живой прогон

Только на постоянно включённой машине. С API-ключом это перенос без изменений кода ([[model-and-budget]]).

## Что не подходит

Vercel и похожие площадки для сайтов: боту нужны долгая работа и постоянный диск. Облачные сессии Claude Code по расписанию тоже отвергнуты ([[model-and-budget]]).

## Хранение

Файлы JSON и JSONL в папке прогона, без базы данных; папки `runs/` и `logs/` не попадают в репозиторий.
