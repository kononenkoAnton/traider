# Traider

Эксперимент: умеет ли LLM-агент торговать акциями сам. Дизайн: `docs/superpowers/specs/2026-11-14-llm-trader-experiment-design.md`.

## Вики проекта: обязательное правило

В `wiki/` лежит база знаний проекта в формате WikiKnowledge. В неё записывается вся информация о проекте.

После каждого изменения (код, конфиг, дизайн, принятое решение, результат пилота или прогона), в том же заходе:

1. Сверься со справочником формата: MCP-сервер `kb-self`, статьи `ai-interaction-guide`, `markup-conventions`, `ai-source-code-annotations`. Синтаксис не угадывай.
2. Обнови или создай статью в `wiki/` по правилам из `wiki/articles/traider-wiki-rules.md`.
3. У каждой категории, чья статья изменилась, обнови блок `<!-- ai:start -->` и поле `modified`.
4. Запусти проверку: `uv run --with python-frontmatter python tools/check_wiki.py`.

Пример готовой вики для ориентира: MCP-сервер с примером вики (здесь он назван `kb-example`; на машине владельца имя сервера может быть другим).

Изменение без записи в вики не закончено. Если `kb-self` недоступен, скажи об этом пользователю и пиши по `traider-wiki-rules`.
